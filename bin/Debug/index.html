项目介绍

基于 .NET Framework 4.8 开发的轻量静态网页服务器，原生运行于 Windows 系统，无需额外安装运行环境，开箱即用。

支持内网、IPv6 外网访问，内置防火墙自动管理、管理员自提权、JSON 配置文件，纯控制台 EXE，无多余依赖。

核心特性

  • 原生 .NET Framework 4.8，Win10 / Win11 系统自带，零安装依赖
  • 双击自动请求管理员权限，自动放行防火墙端口
  • JSON 格式配置文件，可自定义监听端口、默认启动页
  • 自动识别并展示内网 IPv4、公网 IPv6 访问地址
  • 关闭程序自动清理防火墙规则，安全整洁
  • 支持静态 HTML、JS、CSS、图片等各类静态资源

使用方法

  • 1. 将 WebServer.exe、config.json 与网页文件放在同一目录
  • 2. 双击 WebServer.exe，程序自动提权并启动服务
  • 3. 控制台会输出所有可用访问地址，浏览器可直接访问
  • 4. 关闭控制台窗口即可停止服务，自动清理防火墙

配置说明 (config.json)

Port：监听端口，默认 8888

StartPage：默认启动页面，默认 index.html

Project Introduction

A lightweight static web server built on .NET Framework 4.8. Natively supported by Windows, no extra runtime required, ready to use out of the box.

Supports LAN and IPv6 external network access. Built-in automatic firewall management, auto admin elevation and JSON configuration. Pure console EXE with zero redundant dependencies.

Features

  • Based on .NET Framework 4.8, pre-installed on Win10 / Win11
  • Auto request administrator privileges and open firewall port
  • Standard JSON config file, customize port & default page
  • Auto display LAN IPv4 and public IPv6 address
  • Auto clean firewall rules after exit
  • Fully support HTML, JS, CSS, images and other static files

How to Use

  • 1. Put WebServer.exe, config.json and web files in the same folder
  • 2. Double-click WebServer.exe, it will auto elevate and start service
  • 3. All available access addresses are shown in console
  • 4. Close console window to stop service, firewall rules will be removed automatically

Configuration (config.json)

Port: Listen port, default 8888

StartPage: Default homepage, default index.html
